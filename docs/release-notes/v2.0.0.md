v2.0.0 — Electron 에서 Tauri 로

앱의 내부가 **Electron 에서 Tauri 2(Rust 백엔드)로 바뀌었다.** 화면과 기능은 그대로이고, 아래는 v1.x 를 쓰던 사람이 알아야 할 변화다.

### 업데이트하면 일어나는 일 (Windows 설치본, 사용자별 설치)

- v1.x 앱이 새 버전을 알려 주면 [업데이트] → [다시 시작하여 설치] 를 누른다. 새 설치본이 실행되면서 **이전 Electron 판을 자동으로 지우고**(앱 데이터는 남긴다) 새 앱이 뜬다.
- **모든 사용자용(Program Files)으로 설치한 Electron 판은 자동으로 지우지 않는다.** 이전 판의 업데이트는 조용한 설치로 돌아 **안내 창이 뜨지 않으므로**(설치기의 안내는 조용한 설치에서 자동으로 건너뛴다), 업데이트 뒤에도 이전 Antler 가 "설치된 앱"에 남아 있으면 관리자 권한으로 Windows 설정 → 앱 → 설치된 앱에서 직접 제거한다. 두 판이 함께 남아도 새 판은 문제없이 돈다(확인 대상).
- 작업 표시줄에 고정해 둔 이전 아이콘은 풀리거나 깨질 수 있다 — 새 앱을 다시 고정한다(확인 대상).
- 업데이트의 진위는 이제 **서명(minisign)으로 검증**한다. 설치본에는 여전히 Windows 코드 서명이 없다.

### 설정과 로그인

- **저장소 목록·그룹·화면 설정·fetch 자격 증명 도우미 승인은 첫 실행에 자동으로 가져온다**(`%APPDATA%\Antler\antler.config.json` 을 읽기만 한다 — 원본은 고치지 않는다).
- **GitHub·Jira 에는 다시 로그인해야 한다.** 이전 판이 암호화해 둔 토큰은 새 앱이 풀 수 없어 가져오지 않는다.
- GitHub **원격 전용 저장소**는 처음 열 때 이력을 다시 받는다(캐시 폴더는 가져오지 않는다).
- 저장소 설정의 **"항상 허용"(명령을 실행할 수 있는 설정에 대한 승인)은 가져오지 않는다** — 해당 저장소를 처음 fetch 할 때 한 번 다시 묻는다. 창 위치·크기도 가져오지 않는다.

### 없어진 것

- **Windows portable exe 는 없다.** 설치본(`Antler-Setup-<버전>-x64.exe`)만 낸다. portable 을 쓰던 사람은 설치본으로 옮겨 가야 한다. 이전 판의 portable 업데이트는 맞는 파일(`Antler-Portable-<버전>.exe`)을 찾지 못해 자동 확인은 조용히 넘기고, 수동 확인("업데이트 확인")은 "이 환경에 맞는 설치 파일이 릴리스에 없습니다" 오류를 보인다.
- **Linux AppImage 는 없다** — deb 만 낸다(x64). 이전 판의 AppImage 자동 업데이트는 `latest-linux.yml` 을 찾지 못해 알림 없이 멈춘다(확인 대상). 설치본(deb)으로 옮겨 가야 한다.
- **macOS dmg**(Intel·Apple Silicon)와 **Linux deb 는 이전 판의 수동 업데이트가 같은 이름의 새 파일을 찾아 알릴 수 있다**: 이전 판은 `Antler-<버전>-<arm64|x64>.dmg`·`antler_<버전>_amd64.deb` 이름의 자산을 찾고, 이 릴리스에는 `latest-mac.yml`·`latest-linux.yml` 이 없어 GitHub 가 알려 주는 sha256 으로 검증한다(그 값이 없으면 받지 않는다). 실제 동작은 확인하지 못했다(확인 대상) — 알림이 오지 않으면 Releases 에서 직접 받는다.

### 코드 서명이 없다 — 첫 실행 경고

- **Windows**: 브라우저로 내려받아 처음 실행하면 SmartScreen 경고가 뜰 수 있다("추가 정보 → 실행"). 업데이트로 받은 설치본에는 뜨지 않을 것으로 예상한다(확인 대상).
- **macOS**: Apple 개발자 인증서로 서명·공증하지 않았다. 처음 열 때 막히면 **시스템 설정 → 개인정보 보호 및 보안**에서 "그래도 열기"를 누르거나, 터미널에서 `xattr -dr com.apple.quarantine /Applications/Antler.app` 을 실행한다(문구는 실기기에서 확인 필요).
- **Linux**: deb 는 WebKitGTK 4.1 이 있는 배포판(Ubuntu 22.04+ · Debian 12+)이 필요하다.

### macOS · Linux 알려진 한계 (이번 릴리스에서 직접 확인하지 못했다)

- 단축키·환경 표기와 창 단추가 Windows 식으로 보일 수 있다.
- **Windows 밖에서는 GitHub·Jira 토큰을 디스크·키체인에 저장하지 않는다 — 앱을 끄면 로그인이 풀린다.**

### 이전 판의 남은 데이터 정리 · 되돌리기

- 이전 판의 데이터 `%APPDATA%\Antler`(설정·GitHub 캐시·암호화된 토큰 파일)는 **지우지 않았다**. 필요 없으면 직접 지운다. 지우면 Electron 판으로 되돌아갈 수 없다.
- **되돌리려면**: 먼저 새 앱을 제거(Windows 설정 → 앱 → Antler)한 뒤, 이전 릴리스(v1.12.x)의 설치본을 [Releases](https://github.com/Kang-Jacob-GitLB/antler/releases)에서 받아 설치한다(두 판이 같은 바로가기 경로를 써서 겹쳐 두면 서로의 바로가기를 지울 수 있다 — 확인 대상). 이전 판은 `%APPDATA%\Antler` 를 그대로 쓰지만, v2.0.0 에서 바꾼 설정은 반영되지 않는다. 이전 판은 더 이상 고쳐지지 않는다(이 릴리스부터 지원 종료).

### 그 밖의 변화

- 앱을 두 번 실행하면 새 창을 띄우지 않고 이미 떠 있는 창을 앞으로 가져온다.
- 업데이트 확인은 프록시 설정을 따르지 않는다(프록시가 필수인 사내망에서는 확인이 실패할 수 있다 — 릴리스 페이지에서 직접 받는다).
